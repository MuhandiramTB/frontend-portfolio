# **App Name**: TB Portfolio

## Core Features:

- Hero Section: Display a fullscreen hero section with developer name, role, tagline, and call-to-action buttons for immediate engagement.
- Concise Bio: Present a concise 'About Me' section with a professional bio, highlighting skills and experiences.
- Interactive Projects Grid: Showcase projects in a grid layout, complete with project images, names, descriptions, tech stack, and links to GitHub and live demos.
- Tech Stack Showcase: Display tech stack using icons for React, Tailwind CSS, Firebase, Git, GitHub, VS Code, and Figma.
- Dark/Light Mode: Allow light and dark mode as a user preference.

## Style Guidelines:

- Primary color: A calm blue (#5DADE2) to evoke trust and professionalism.
- Background color: Light grey (#F0F4F8) to provide a clean and modern feel in light mode, and dark grey (#333333) in dark mode.
- Accent color: A vivid orange (#FF851B) to highlight key elements like call-to-action buttons and links.
- Clean, sans-serif font for headings and body text to ensure readability.
- Simple, line-based icons for the tech stack and social media links.
- Minimalist layout with a focus on white space and clear section divisions.
- Smooth scrolling and subtle reveal animations for elements as the user scrolls.
